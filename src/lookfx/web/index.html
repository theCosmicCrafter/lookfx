Limitations
  • SDR only. HDR sources (PQ / HLG transfer, BT.2020 primaries) are tone-mapped to SDR on decode, not passed through; frames are processed as 16-bit sRGB and every output is tagged BT.709. The source header shows an HDR → SDR badge for such clips.
  • EXR is input-only (decoded to sRGB). Outputs are PNG / TIFF / JPEG stills, PNG / TIFF sequences or video. Stills and sequences play at 24 fps unless the fps field in the source header sets another rate.
  • Audio is copied, not processed. A ranged render keeps the matching slice of the audio; it is re-encoded (AAC / PCM) when the range does not start at 0 or the codec does not fit the container. A sequence output gets the audio as a .wav sidecar next to the sequence (full-range renders; the Queue shows its path).
  • One clip per project, with media paths stored absolute plus a relative copy; use Relink clip when a file moves. A project opened next to its media resolves a missing path relative to the project file.
  • A ranged render reuses the clip solve when it covers the range and only re-solves when none exists.
  • Windows desktop shell only; the browser UI (lookfx serve) is the cross-platform path.
